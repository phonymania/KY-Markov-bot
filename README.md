# KY-Markov-bot
空気の読めないマルコフ連鎖botの動作コードです。

Twifork（https://github.com/PawiX25/twifork ）を使用しております。
# 使用方法
1. このリポジトリをクローンします。
2. markovifyとJanomeをインストールします
3. 同様のディレクトリにsource.txtファイルを作ります。
4. 学習させたい文章を入れます（同じディレクトリに入れているscraping.pyのコードの途中のURLを変更し実行するとスクレイピングが出来ます。許可されているサイトで行ってください）。
5. 同様のディレクトリで.envファイルを作り、
```
X_USERNAME=
X_EMAIL=
X_PASSWORD=
X_AUTH_TOKEN=
X_CT0=
```
と入力し、ユーザーネーム、メールアドレス、パスワード、クッキーを入力します。（クッキーの取得方法はそれぞれでググってください）

5. videosフォルダを作り、一緒に投稿したい動画をvideosフォルダにぶち込みます。
6. test_bot.pyで投稿をしないテストが出来ます。文章が少ないとうまく文章を生成できない可能性があるためテストは行っておいてください。
7. テストが出来たら、bot.pyを実行します。
8. うまく生成が出来たら数十秒待ってください。投稿されます。
# 注意点
1. 行いすぎると凍結のリスクがあります。
2. 検索で検知しているため、シャドウバンされている人は使えません。
3. 非公認APIを使用しているため凍結などのリスクは常につきまといます。
4. このプログラムはAIを使用しています。
